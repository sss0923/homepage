# 苏弈秋个人首页

一页式产品经理个人作品集，使用原生 HTML / CSS / JavaScript 与 GSAP 构建。

## 本地预览

```powershell
python -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## 替换内容

- 首屏个人照片：`assets/portrait.jpg`。
- 成长影集：`assets/gallery/gallery-01.jpg` 至 `gallery-05.jpg`，按时间顺序排列。
- 项目图：替换 `.work-image` 和 `.project-placeholder` 内占位内容。
- 如有在线作品链接，可直接把对应 `.work-card` 改为 `<a>`。
